## NON-ACTIONABLE APPENDIX

### A1 — Root cause behind S2: the DTO collapses a discriminated union into nullable fields

`RefusalLog` (`read.ts:64-79`) carries `archivedLocations: ArchivedLocationSummary | null` (account-only) and `archivedPeriods: ArchivedPeriod[]` (location-only), with "null / empty means not-applicable-in-this-scope" as the convention. The scope that decides which half is meaningful is an *input* to `getRefusalLog` and is then discarded from the output, which is why `RestraintReport` needs an out-of-band `scope` prop at all. Its own comment (`RestraintReport.tsx:23-28`) correctly rejects re-deriving scope from `archivedLocations !== null` — but the alternative it chose (client state) is weaker than the third option (server echo). A discriminated return (`{ kind: 'account'; archivedLocations } | { kind: 'location'; archivedPeriods }`) would make the whole class unrepresentable; a single `scope` field on the payload gets 90% of that for one line. Filed as a design note rather than a finding because S2's correction resolves the practical consequence.

### A2 — Answering the brief's questions directly

- **Is `getRefusalLog` a deep module?** Yes on the axis it was judged on: the three-query *mechanism* is fully hidden (callers never learn there is a coverage read, an archived-location count and an audit-log pairing), the `EXISTS`-not-`JOIN` fan-out defence is internal, and the `subject_resolves` / `linkKind` resolution is server-side by design. It leaks in one place only — the scope discriminator (A1). The route consumes it in two lines per branch, which is the honest test.

The file is 74 lines to agent-team's 33 solely because of a 30-line header, so the header's own "anything that makes this file longer than that one is logic in the wrong module" is technically self-refuting — but no logic moved, so this is a note, not a finding.

I did **not** raise this. `vocabulary.ts:30-33` draws its boundary at **presentation vs vocabulary**, not at "one concern per file", and it explicitly assigns *all* owner-facing labels and sentences to this surface. Everything in the file is on the presentation side of that line, and the closest in-repo analogue (`BatchReport.tsx`, which the file's own formatter comment cites) has the same shape. Splitting on the file's internal `──` rules would produce modules with one caller each — which `.claude/CLAUDE.md` bans outright ("no abstractions for a single caller").
- **The four parallel tables.** `CATEGORY_COPY` / `CATEGORY_HEADING` are both `Record<RefusalCategory, string>`, so `strict` typecheck already forces them to move together — an issue enforced by green tooling, skipped per the brief. `hrefFor` / `LINK_LABEL` are the genuinely mismatched pair, and that is S7.
