The SVG is the app's current mark. The PNG and PDF are existing exports; compare their appearance and export quality before using them for a new deliverable. The mark and text wordmark are separate in the app. No clear-space measurement, minimum print size, or monochrome export has been established by this consolidation; do not invent one and present it as an existing brand rule.

There is no single palette for every RepWorth surface. Landing uses its own dark palette; Island owns public marketing/auth/admin surfaces; Console owns the authenticated app. Select a system before extracting colors or fonts.
