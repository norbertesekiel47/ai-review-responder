# System reference for the critic = docs/design/island/DESIGN.md AS AMENDED on 2026-08-19

The Island Style Reference (`/Users/norbertesekiel/Developer/startups/RepWorth/docs/design/island/DESIGN.md`)
is the system of record, with these user-approved amendments for the marketing rebrand:

1. Palette: a NEW palette is allowed. Ink `#15191a` (text, hairlines, the dark surface, the Judge
   bar), bone `#f6f6f2` (island canvas), paper `#fff` (cards), forest `#2e5b4f` (the single
   ACTION colour: button fills and their arrow discs, "live" dots and the posted/verdict dots).
   Bar-only accents (6px card bars and 8–10px dots, never text, never broad fills):
   sage-bar `#8fb99b`, teal-bar `#6f9d8f`, mist `#8fb1e6`, blush `#eca396`, gold `#dcb94a`. Review stars are ink
   (ratings are content, not action). The sage marquee field `#D2E0D3` behind the island is unchanged.
2. Type: ONE family, ONE weight — DM Sans 400 everywhere. Hierarchy by size only. No Plus Jakarta,
   no Fraunces, no bold. Normal letter-spacing; no negative tracking; no viewport-scaled type.
   Display sizes pin the variable font's optical size so stroke weight stays uniform.
3. Nav + footer are rebranded in the same system.
4. Everything else in DESIGN.md still applies: island wrapper (bone card on the sage field, large
   radius, the island's own soft shadow is the container and stays), inline SVG only, decorative
   wrappers aria-hidden, no fake metrics/testimonials/logos/avatars (illustrative samples must be
   labelled as such), no hype copy, no orb/blob/neon, accessible contrast (text ≥ AA), no
   overflow-hidden on the page root, reduced-motion respected. The hero's blurred wash is an
   approved, deliberate exception (Ada's signature move), confined to the hero and fading to bone
   before the hero ends. The real logo mark (teal + gold) is the brand mark and is not in scope.
