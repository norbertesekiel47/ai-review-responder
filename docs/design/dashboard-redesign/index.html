Dashboard redesign preview

Young Serif + DM Sans · warm field · double-bezel cards. Visual exploration only. Click into any screen below.

IA superseded (2026-06-19). These mockups show an older information architecture (a separate /dashboard/insights route and the needs-action reviews queue on the dashboard). The current IA settled in two steps: first the /dashboard/insights route was removed and the reviews queue moved to its own /dashboard/reviews page; then the dashboard became a two-second glance and the analytics (trend / velocity / ranking) moved to a new /dashboard/analytics page. Net: /dashboard = glance, /dashboard/analytics = the charts, /dashboard/reviews = the queue; /dashboard/insights is no longer a live route and the analytics are not on the dashboard. Authoritative current IA: docs/superpowers/specs/2026-06-19-glance-dashboard-analytics-history-design.md. Kept here as an archived visual reference.
