| `delivery-status.ts` | **(#890)** The THREE named owners of the send lane's delivery-status subsets, each answering a DIFFERENT question: `CANCELLABLE_DELIVERY_STATUSES` (may an owner still cancel it — the Halt latch's row predicate), `LIVE_DELIVERY_STATUSES` (is anything still live — settledness), `DISPATCHED_ARRIVAL_STATUSES` (what can a dead send job leave behind), plus `WITHDRAWABLE_BATCH_STATES` (`isWithdrawableState` derives from it) and `isCancellableDeliveryStatus`. SQL sites keep their LITERAL spellings (query-shape pins assert them by value); `__tests__/delivery-status.test.ts` mechanically ties those literals back to these constants so a one-sided widening fails a test. |
