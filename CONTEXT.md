# RepWorth Domain Glossary (seed)

This glossary is multi-context. Read `CONTEXT-MAP.md` for the list of contexts and the file that owns each term.

Historical docs that cite `CONTEXT.md → **Term**`: look the term up in `CONTEXT-MAP.md`, which names every term under the `docs/context/*.md` file that defines it.

The former single-file glossary was split verbatim in the agent-context restructure: the seed glossary and cross-cutting terms became `docs/context/core-*.md`; every `## ` section became its own `docs/context/<section>.md` (the send-mode section is three parts). Nothing was reworded; do not add new terms here — add them to the owning context file and to the map.
